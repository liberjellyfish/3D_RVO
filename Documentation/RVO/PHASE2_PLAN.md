# Phase 2：二维网格导航与动态避障

## 范围和实现顺序

沿用 float3/XZ 圆盘、固定 Tick、双缓冲 World 和原有模块接口。Phase 1 正式 100/1k/10k 压测继续暂缓。新增独立演示，不改变 Phase 1 场景的算法对照含义。

1. **地图与几何**：单层规则网格，障碍是占据格的轴对齐方块；独立维护占据、净空、可行走格、连通域、地图版本。圆盘按半径加安全余量膨胀障碍；采用保守方形膨胀，拐角可能损失少量可行空间。
2. **寻路**：八邻域 A*，octile 启发式、可减键二叉最小堆、稳定索引破同分。禁止斜穿角；边、起终点连接及路径前瞻都做相同的连续线段净空检查。先验证基础实现，后续再评估 JPS、分层寻路或共享目标缓存。
3. **路径状态**：路径使用按 Agent 分段的扁平缓冲，保存 Agent ID、请求序号、地图版本、状态与游标。地图变化、目标变化、偏离路径导致连接不可见时重规划；无路时 preferred 为零并显示状态。
4. **局部避障**：动态 Agent 复用 ORCA 几何；静态方块与外边界使用完整责任的保守支撑半平面，与动态约束一起进入现有二维优化器。静态障碍不是零速度 Agent。路径只决定 preferred，积分器仍只积分最终速度。
5. **整步安全证书**：在求解器内部检查整段运动对膨胀障碍、地图边界、所有动态 pair 的扫掠距离。失败时统一缩短所有速度对应的时间前缀并重新检查，必要时全部停车。不能逐 Agent 独立停车，否则会使其他 Agent 的预测失效。记录退让次数和比例。这是新增的集中式安全策略，不援引原始 ORCA 对被修改速度的证明。
6. **随机刷新**：固定 seed 初始化；定时或按钮请求刷新，在 Preferred 阶段（无未完成地图读取）提交。每批候选避开当前圆盘和目标，验证所有 Agent 到目标的净空连通性和路径；不合法则保留旧地图。新地图具有新版本，统一使路径过期。障碍在两次刷新间保持静止。
7. **演示与诊断**：单独 Phase 2 场景、默认 16 Agent、障碍网格与路径/目标显示、暂停/单步/重置/换 seed/刷新按钮，显示地图版本、无路数、安全退让、到达与扫掠碰撞。Phase 1 HUD 同步适度增大字号并允许滚动。

## 模块和所有权

`NavigationSettings → GridNavigation（地图、请求与路径跟随） → GridAvoidanceSolver（动态/静态约束及安全证书） → PlanarEulerIntegrator`。

`Phase2ModuleFactory` 装配到原有 `SimulationWorld`。地图只在导航阶段更换，求解器借用当前地图；路径和地图由导航模块持有，Native scratch 由求解器唯一释放。导航网格与邻居 Spatial Hash 分离。Unity Bootstrap/Presenter 只控制和显示，不实现 A* 或碰撞修正。

第一版导航和组合求解使用主线程参考实现；邻居查询、积分继续支持既有 Jobs/Burst。不给整个 Phase 2 标注全 Burst，也不提前承诺 10k 性能。地图重建与 A* 搜索有显式重规划成本；安全全 pair 检查为 O(N²)。

## 验证和完成条件

- 几何：负坐标、边界、不同半径净空、障碍穿越、斜角、狭窄通道。
- A*：无路、起终点非法、起终点相同、独立 Dijkstra 最短代价对照；路径所有段可通行。
- 刷新：相同 seed 可复现、版本更新、拒绝非法候选、当前圆盘/目标不被覆盖，地图更换后重规划。
- 集成：多个 seed、多 Agent、两种执行后端、定时刷新；每 Tick 独立检查动态扫掠与静态障碍，检查速度上界、平面不变量与生命周期。
- 可用性：演示资产可直接打开，PlayMode 验证渲染、暂停、单步、刷新、重置与释放；报告实际运行结果，未运行项目明确注明。

**限制**：无碰撞依赖合法非重叠初态、受控地图刷新、有限数值误差和当前瞬时变速模型。全局安全退让会降低吞吐，单通道对向或目标堵塞仍可能停滞；保证任意多 Agent 都能最终到达需要后续预约/优先级交通管理，不能仅靠 A* + ORCA 宣称解决。Phase 2 的静态支撑约束是保守替代，并非完整 RVO2 墙段/凸角实现。

依据：[ORCA 原始项目](https://gamma-web.iacs.umd.edu/ORCA/)。

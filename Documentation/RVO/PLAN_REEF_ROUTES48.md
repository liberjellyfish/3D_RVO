# 本轮范围与执行顺序

1. 保留 CausticRaw 与共享双时间纹理生成。在共用采样入口实现世界空间稳定三角随机采样，显式纹理导数，保留 Repeat 对照开关。对大平面近景、俯视、斜视、连续时间和远处 mip 做 GPU 验证。
2. 礁石从 20 个代理扩展至 48 个。保留现有主体和出生带，添加错位礁墙、上下通行的洞口、并行支路、汇合前缓冲区。网格与导航代理一起离线重建。
3. 同一 1024 agents、seed 7、30 Hz、现有 A* 参数，对新旧地图各跑 3 次 1800 ticks。独立预热；记录首路径等待、到达、拥堵、粗图回退、Tick P50/P95/P99、阶段耗时、静态穿障与抽样成对安全。
4. 运行有关导航/生成及焦散回归检查，保存可复现命令、画面与测量报告。区分 Editor 无渲染 Tick、渲染帧与 GPU 时间，不外推为更高 agent 数量的性能承诺。

本轮不实现 JPS/JPS+，不修改搜索预算，不扩展 2048/4096 agents。

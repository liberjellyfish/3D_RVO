## 边界与后续

1. 这是 **Phase 2 首版**。A*、地图构建和组合求解目前为托管参考实现；地图刷新会重新构建净空/连通域并逐 Agent 验证路径，存在同步峰值。未完成异步寻路预算、地图增量更新、JPS 和组合求解 Burst。
2. 障碍按格子方块表示，并用方形膨胀保守覆盖圆盘，可能牺牲圆角处的通行空间。演示配置要求 radius + margin < 0.49 × cellSize；应通过增大格宽满足这一条件。
3. 静态支撑半平面不是完整的 RVO2 连续墙段/凸角实现。安全层基于瞬时变速、合法初态、受控地图刷新与数值余量，修改速度后重新检查，不直接引用原始 ORCA 安全证明。
4. 全 pair 安全检查为 O(N²)，一次冲突可能让整个群体减速；任意窄道对向、密集目标堵塞的最终到达性尚未保证。后续需要交通优先级或时空预约。
5. 首版导航场景为同半径 Agent；网格几何有半径参数和测试，但没有加入不同半径的多套连通图缓存。
6. 正式压力测试、Player 构建、长时运行和跨平台验证未进行。Phase 1 全量测试中的旧小规模调查不等于正式规模验收。

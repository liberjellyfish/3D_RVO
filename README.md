# 3D_RVO

Unity 6000.0.63f1 项目：二维 VO/RVO/ORCA 对照、三维体素导航与球体避障、GPU 鱼群及水下渲染。

- **[项目整体结构与数据流](Documentation/RVO/ARCHITECTURE.md)**：完整框架、运行过程、数据所有权与源码阅读路线。
- [运行说明与文档索引](Documentation/RVO/README.md)：当前主场景、配置、历史报告。
- [验证与复现指南](Documentation/RVO/VALIDATION.md)。

当前主场景为 `Assets/RVO/Demo/OceanReef/OceanReefLive.unity`，默认 2048 条真实导航鱼。用 Unity 打开后进入 Play，或选择 **Tools → RVO → Open Reef Presentation**。
